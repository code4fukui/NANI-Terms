# README example (English)

Paste the following into your project's README.

```md
## Terms of Use

This service is provided under [NANI Terms v1.0](https://github.com/code4fukui/NANI-Terms/blob/main/versions/v1.0/TERMS-en.md).

Additional terms: [Service-specific additional terms](YOUR-ADDITIONAL-TERMS-URL)
```

Remove the last line if there are no additional terms. If additional terms are used, identify the operator, effective date, and which terms prevail in the event of a conflict.
