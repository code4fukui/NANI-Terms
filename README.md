# NANI Terms

**No Warranty, As-Is, No Liability, It's on you.**

無料・実験的・小規模なサービスを公開するときのための、シンプルな標準利用規約。

## NANI Terms とは

NANI は **No Warranty, As-Is, No Liability, It's on you.** の略です。日本語なら「保証なし。現状のまま。責任は限定的。使うかどうかはあなたの判断で。」というニュアンスです。

個人開発、試作品、研究・教育用ツール、無償 API、期間限定企画などが、長大な規約を一から作らずに採用できる汎用のベースラインです。サービス固有の条件は本文を改変せず「追加条件」として組み合わせられます。

## なぜ作ったか

小さなサービスにも、停止・変更、データ消失、外部 API などの現実的なリスクがあります。一方、毎回ゼロから規約を作るのは重い。そこで、短く読め、版を固定して参照でき、開発者が採用しやすい共通土台を目指しました。

## 向いているサービス

- 無料または実験的な Web サービス、個人開発、プロトタイプ
- 小規模な API、AI 生成ツール、研究・教育用サービス
- 継続提供やデータ保存を保証しない期間限定サービス

有料サービスにも利用できますが、料金、更新、解約、返金などの追加条件が通常必要です。医療、金融、決済、通信、継続課金、大量の個人情報を扱うサービス、事業者と消費者の利害が大きいサービスには、NANI Terms だけでは不十分です。

## 採用方法

1. [NANI Terms v1.0 日本語正式版](versions/v1.0/TERMS-ja.md)を読み、サービスに適するか確認します。
2. 利用画面やフッターから、採用する言語版とバージョンへリンクします。
3. 運営者、適用開始日、準拠法・裁判管轄、料金、プライバシーなど必要な事項を「追加条件」で定めます。
4. 公開前に、サービスの法域と内容に応じて専門家へ確認します。

コピペ用の標準表記:

```text
本サービスには NANI Terms v1.0 が適用されます。
```

GitHub Markdown:

```md
本サービスには [NANI Terms v1.0](https://github.com/YOUR-ACCOUNT/NANI-Terms/blob/main/versions/v1.0/TERMS-ja.md) が適用されます。
```

HTML:

```html
<p>本サービスには <a href="https://github.com/YOUR-ACCOUNT/NANI-Terms/blob/main/versions/v1.0/TERMS-ja.md">NANI Terms v1.0</a> が適用されます。</p>
```

英語表記:

```text
This service is provided under NANI Terms v1.0.
```

詳しい例は [Web サイト用](examples/website-ja.html) と [README 用](examples/README-ja.md) にあります。`YOUR-ACCOUNT` は公開先の GitHub アカウント名に置き換えてください。

## 超短縮版

> 保証しません。止まるかもしれません。データが消えるかもしれません。自己責任で使ってください。

> No warranties. It may stop. Data may be lost. Use it at your own risk.

これは NANI を一言で説明する要約であり、正式な規約本文ではありません。採用時は必ず版を指定して正式版へリンクしてください。

## バージョンと追加条件

`v1.0` は固定版です。新しい版が公開されても既存サービスへ自動適用されません。採用する版を明記し、過去版へのリンクを維持してください。

サービス固有の追加条件は別文書にし、NANI Terms と矛盾する場合の優先関係を明記してください。公式本文を編集した文書を「NANI Terms v1.0」または公式版であるかのように表示しないでください。

## 法的注意事項

NANI Terms は一般的なひな型であり、弁護士その他の専門家による個別の法律相談の代替ではありません。全面免責を保証するものでもありません。消費者契約法その他の強行法規、故意・重過失等に関する責任、個人情報保護、特定商取引、資金決済、医療、金融、通信など、適用される法令に応じた対応が別途必要です。プライバシーポリシー、表示、同意取得、追加規約もサービスに応じて用意してください。
